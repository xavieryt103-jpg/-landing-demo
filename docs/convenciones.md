# Convenciones del equipo

Decision tomada en la Discussion "Reglas para nombrar ramas y commits".

## Ramas
- feature/nombre-corto: funcionalidades nuevas
- fix/nombre-corto: correcciones
- hotfix/nombre-corto: errores urgentes en produccion

## Commits
- feat: funcionalidad nueva
- fix: correccion
- docs: documentacion
